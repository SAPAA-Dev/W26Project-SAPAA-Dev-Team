# User Story Summaries

The full stories and acceptance tests are in [User Stories](user-stories.md). The sprint plan is in
[Project Management](project-management.md). The code after each story title is its charter project.
The list of charter projects is in [User Stories](user-stories.md#charter-projects).

## Sprint 1

Sprint 1 has no user stories. It is documentation and discovery.

## Sprint 2

- **US 1.0.1 - Add User Profiles** (Charter 2b)
    - Steward views steward profiles with skills, focus areas, and SIR count.
- **US 1.0.2 - Allow Editing Own Profile** (Charter 2b)
    - Steward edits own profile only. Name and email stay required.
- **US 2.0.2 - Allow Admins to Add New Sites** (Charter 1)
    - Admin adds a new site through the app UI.
- **US 2.0.3 - Deactivate and Reactivate a Site** (Charter 1)
    - Admin deactivates and reactivates a site.
- **US 2.0.4 - Delete a Site** (Charter 1)
    - Admin deletes a site after confirmation.
- **US 2.0.5 - Update a Site** (Charter 1)
    - Admin edits site page fields.
- **US 2.0.6 - Search and Filter Sites by County on the Map** (Charter 2c)
    - Steward searches and filters sites by county on the map.
- **US 2.0.10 - Add links to Site Page** (Charter 1)
    - Steward opens SAPAA and iNaturalist links from a site page.
- **US 3.0.2 - Steward Designation** (Charter 2b)
    - Admin assigns a steward to a site.
- **US 4.0.6 - Demote Photo Identifier to optional field** (Charter 1)
    - Steward submits a SIR without a photo identifier.
- **US 5.0.4 - Sign Out Properly** (Charter 1)
    - User signs out and stays signed out on shared devices.
- **US 7.0.1 - Let Stewards Export Their Own Reports** (Charter 1)
    - Steward exports own SIR as a PDF.
- **US 7.0.5 - Delete an Image and Clean Up After It** (Charter 1)
    - Admin deletes an image and removes the stored file.
- **US 7.0.6 - Export More Than 50 Site Inspection Reports** (Charter 1)
    - Admin exports more than 50 SIRs at once.
- **US 7.0.7 - Hide Fields on a SIR Before Export** (Charter 1)
    - Admin hides selected fields before SIR export.
- **US 7.0.8 - Delete a Site Inspection Report** (Charter 1)
    - Admin deletes a SIR after confirmation.

## Sprint 3

- **US 1.0.3 - Show history of Site Inspections on a Steward's Profile** (Charter 2b)
    - Steward views past inspections from a steward profile.
- **US 1.0.4 - Aggregate User Activity and Contributions on a user's profile** (Charter 2b)
    - Steward views activity stats on a steward profile.
- **US 2.0.1 - View Sites and Past Visits on an Interactive Map** (Charter 2c)
    - Steward views sites and past visits on an interactive map.
- **US 2.0.8 - View a Site's Details From the Map** (Charter 2c)
    - Steward opens site details from the map.
- **US 2.0.9 - Upload a GPX Track of a Site Visit** (Charter 2c)
    - Steward uploads a GPX track for a site visit.
- **US 2.0.14 - Color Map Sites by Type** (Charter 2c)
    - Team: Blue (Aaron, Zanab, Abhinav).
    - Steward sees boundary colors set by an Admin for one site or all sites of a type. Different types can use the same color. Colors do not have to match the SAPAA website.
- **US 1.0.6 - Select and Edit Skills and Focus Areas** (Charter 2b)
    - Team: Red (Saumya, Chris).
    - Instead of free text, select and edit skills and focus areas from a predetermined list. Include an option for 'Other'.
- **US 2.0.12 - Score a Site for To-Visit Priority** (Charter 1)
    - Team: Red (Saumya, Chris).
    - Admin scores a site. Steward views the to-visit priority.
- **US 2.0.13 - Flag Site Points That Are a Year Old** (Charter 1)
    - Team: Red (Saumya, Chris).
    - Admin views a reminder when site scores are one year old.
- **US 3.0.3 - Export all digital files from SIR-SAPAA** (Charter 1)
    - Team: Red (Saumya, Chris).
    - Admin exports all images and digital files at once.
- **US 3.0.4 - Add a Steward Without an Account** (Charter 2b)
    - Team: Red (Saumya, Chris).
    - Add a steward by name, email and phone number without requiring them to have an account so that their details can be shown on a site page.
- **US 4.0.2 - Offline and Online Map Layers** (No charter, team request)
    - Steward uses map layers offline and online.
- **US 4.0.4 - Edit My Previous Inspections** (Charter 1)
    - Steward edits own past inspections on the web.
- **US 5.0.2 - Reset a Forgotten Password** (Charter 1)
    - User requests an email, verifies the code, then sets a new password without admin help.
- **US 6.0.1 - Store Each Site's Geometry From the Shared Source** (Charter 2c)
    - Each site stores boundary and centre point from the shared KML source.

## Sprint 4

- **US 1.0.5 - Earn Points for Inspection Activity** (Charter 2b)
    - Steward earns points for visits, photos, and inspection activity.
- **US 5.0.5 - Request Access During Email Sign-Up** (Charter 2b)
    - Prospective user requests access while creating an email and password account.
- **US 5.0.6 - Complete an Access Request With Google or Microsoft** (Charter 2b)
    - Prospective user completes the access request after Google or Microsoft sign-in.
- **US 5.0.7 - Review and Decide Access Requests** (Charter 2b)
    - Admin reviews private request details and approves or rejects access.
- **US 5.0.8 - Manage Access Terms** (Charter 2b)
    - Admin edits the two access terms for new requests.
- **US 5.0.9 - View My Access-Request Status** (Charter 2b)
    - Applicant sees whether a request is pending, approved, or rejected.
- **US 7.0.3 - See All Inspections in One View** (Charter 1)
    - Admin views summary counts across all SIRs.
