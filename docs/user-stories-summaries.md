# User Story Summaries


Sprint 2:
- **US 1.0.1 - Add User Profiles**
    - Steward views steward profiles with skills, focus areas, and SIR count.
- **US 1.0.2 - Allow Editing Own Profile**
    - Steward edits own profile only. Name and email stay required.
- **US 2.0.2 - Allow Admins to Add New Sites**
    - Admin adds a new site through the app UI.
- **US 2.0.3 - Deactivate and Reactivate a Site**
    - Admin deactivates and reactivates a site.
- **US 2.0.4 - Delete a Site**
    - Admin deletes a site after confirmation.
- **US 2.0.5 - Update a Site**
    - Admin edits site page fields.
- **US 2.0.6 - Search and Filter Sites by County on the Map**
    - Steward searches and filters sites by county on the map.
- **US 2.0.10 - Add links to Site Page**
    - Steward opens SAPAA and iNaturalist links from a site page.
- **US 3.0.2 - Steward Designation**
    - Admin assigns a steward to a site.
- **US 4.0.6 - Demote Photo Identifier to optional field**
    - Steward submits a SIR without a photo identifier.
- **US 5.0.4 - Sign Out Properly**
    - User signs out and stays signed out on shared devices.
- **US 7.0.5 - Delete an Image and Clean Up After It**
    - Admin deletes an image and removes the stored file.
- **US 7.0.6 - Export More Than 50 Site Inspection Reports**
    - Admin exports more than 50 SIRs at once.
- **US 7.0.7 - Hide Fields on a SIR Before Export**
    - Admin hides selected fields before SIR export.
- **US 7.0.1 - Let Stewards Export Their Own Reports**
    - Steward exports own SIR as a PDF.
- **US 7.0.8 - Delete a Site Inspection Report**
    - Admin deletes a SIR after confirmation.


Sprint 3:
- **US 1.0.3 - Show history of Site Inspections on a Steward's Profile**
    - Steward views past inspections from a steward profile.
- **US 1.0.4 - Aggregate User Activity and Contributions on a user's profile**
    - Steward views activity stats on a steward profile.
- **US 2.0.1 - View Sites and Past Visits on an Interactive Map**
    - Steward views sites and past visits on an interactive map.
- **US 2.0.8 - View a Site's Details From the Map**
    - Steward opens site details from the map.
- **US 2.0.9 - Upload a GPX Track of a Site Visit**
    - Steward uploads a GPX track for a site visit.
- **US 2.0.11 - Show Safety Information for a Site**
    - Steward views safety data for a site. Only Admin edits it.
- **US 4.0.2 - Offline and Online Map Layers**
    - Steward uses map layers offline and online.
- **US 4.0.4 - Edit My Previous Inspections**
    - Steward edits own past inspections on the web.
- **US 4.0.5 - iNaturalist integration**
    - Steward selects images from an iNaturalist account in a SIR.
- **US 4.0.7 - Show the Top iNaturalist Observations for a Site**
    - Steward views up to 5 top iNaturalist observations for a site.
- **US 5.0.2 - Reset a Forgotten Password**
    - User resets a password without admin help.
- **US 6.0.1 - Store Each Site's Geometry From the Shared Source**
    - Each site stores boundary and centre point from the shared KML source.






Sprint 4:
- **US 1.0.5 - Earn Points for Inspection Activity**
    - Steward earns points for visits, photos, and inspection activity.
- **US 2.0.12 - Score a Site for To-Visit Priority**
    - Admin scores a site. Steward views the to-visit priority.
- **US 2.0.13 - Flag Site Points That Are a Year Old**
    - Admin views a reminder when site scores are one year old.
- **US 3.0.3 - Export all digital files from SIR-SAPAA**
    - Admin exports all images and digital files at once.


- **US 7.0.3 - See All Inspections in One View**
    - Admin views summary counts across all SIRs.
- **US 7.0.4 - Compare One Question Across Years**
    - Steward compares answers for one question across years.
